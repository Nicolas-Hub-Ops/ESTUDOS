# 🧠 Pensamento Computacional

É a capacidade de **resolver problemas de forma lógica e organizada**, dividindo problemas grandes em partes menores.

### 🔹 Principais conceitos

| Conceito | Significado |
|---|---|
| **Decomposição** | Dividir um problema grande em partes menores |
| **Reconhecimento de padrões** | Identificar coisas que se repetem |
| **Abstração** | Focar apenas nas informações importantes |
| **Algoritmos** | Criar uma sequência de passos para resolver um problema |

---

# 💻 Lógica de Programação

É a forma de **organizar o pensamento para criar instruções que o computador consiga executar**.

### 📝 Exemplo

**Problema:** descobrir se uma pessoa pode dirigir.

```text
1. Receber a idade
2. Verificar se a idade é maior ou igual a 18
3. Se for, permitir a direção
4. Caso contrário, negar
```

# 🐍 Paradigmas de Programação

Paradigmas de programação são formas de organizar e estruturar o código para resolver problemas.

Neste resumo veremos dois paradigmas importantes:

- **PP** → Programação Procedural
- **POO** → Programação Orientada a Objetos
